# Operational and Research Roadmaps

## 1. HP automation takeover
Verify actual Windows and source; back up existing `Domino_Data`; run bounded local task; enable and verify Windows scheduler; implement approved authenticated outbound/inbound transport; reject replay and untrusted commands; test stop, restart, 8h/24h/72h/168h reliability. GitHub commits are not ChatGPT messages.

## 2. Priority control
Editable owner policy: automation → priority intelligence → finance → other concurrent branches; audit all owner changes, task dependencies, errors and suggestions.

## 3. Revenue
Verify one real offer and demand → authorize listing/contact → fulfill → verify payment and costs → preserve evidence → repeat when measured success supports it.

## 4. Conversation history bridge
Export both accounts with consent → private original-preserving archive by account/source/date → retain contradictions → compare hypotheses → let owner approve new rules; never invent missing conversations.

## 5. Automatogenesis science
Declare a previously unreachable modeled goal → find missing observation/operator → generate test → compare matched-budget baseline → falsify alternatives → independent outcome verification and honest novelty check.

## 6. Living RPG
Map audited real work to quest events; create engaging UI; test user experience; then optional mixed-reality layer, without buying hardware prematurely.

## 7. Conversation-driven HP operator — top operational objective
Owner uses phone voice/text through their usual ChatGPT account; assistant dispatches structured jobs via an authorized private GitHub mailbox to the HP's Python worker, which records receipts. Avoid unsolicited discussion. Verify actual phone-originated dispatch, HP execution, duplicate suppression, returned evidence and scheduling before claiming a complete connection. See [design](HP_CHAT_CONTROL.md).

## 8. Public-by-default evidence releases
Publish source-coded experiments, negative results, public project-level finances, approved creative source and the master registry. Keep confidential credentials and third-party private material out of public GitHub. See [policy](PUBLICATION_POLICY.md).
