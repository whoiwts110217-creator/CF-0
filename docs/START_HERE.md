# Start Here — Caveman Focus

**Founder:** Kiara Lynn Rose Smith  
**Method:** simplify complexity without losing essentials; **guess → hypothesis → evidence → proof**.

Caveman Focus is an experimental system for reducing repetitive work by coordinating AI-assisted tasks, explicit priorities, and verifiable execution. The initial operating target is a low-resource Windows HP computer. It is **public developer-preview source**, not a finished product.

## Choose a path

- **What has actually worked?** Read the [current evidence-based status](PROJECT_STATUS.md) and [HP demonstration](CF0_FAST_LANE_MILESTONE_2026-11-05.md).
- **Want to inspect or test the software?** Begin with [relay source](../relay/), [tests](../tests/), and [CF-200 task engine](../automation_200/). Review code and use offline/read-only tests before configuring any live relay. There is not yet a verified one-click fresh-user setup.
- **Want the larger vision?** Read the [master plan](CAVEMAN_FOCUS_MASTER_PLAN.md), [rulebook](../CAVEMAN_FOCUS_RULEBOOK_v0.1.md), and [full public archive index](PUBLIC_DEVELOPMENT_SNAPSHOT_2026-11-06.md).

## Owner-defined operating priorities

1. **Automation:** execution, transport, scheduling, receipts and recovery; currently eliminate the human PowerShell copy/paste loop.
2. **Priority intelligence:** make owner decisions govern task selection, overrides and accountability.
3. **Financial operations:** legitimate products, donations and grants; only verified collected payments count as income.
4. **Other projects concurrently:** research, creative work and experiments when resources permit.

Earlier cash-first efforts and earlier Sidecar prototypes are historical stages, not replacements for this priority order.
