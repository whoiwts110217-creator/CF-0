# Research — Automatogenesis and New Capabilities

**Automatogenesis** is a proposed research direction: study the circumstances in which automation acquires provably new operational abilities by altering observation, model classes, operations or resource arrangements. The name does **not** establish a new recognized scientific field.

| Research program | Tested/proposed contribution | Boundaries |
|---|---|---|
| Reality Compiler v0.1 | Counterfactual arrangement and missing-verb candidates | Prewritten alternatives |
| Affordance Forge v0.2–v0.3 | Synthesize bounded data-transform rules | Known grammar |
| Gap Foundry v0.6 | Detect/repair missed RSS feed tail | Four defined strategies |
| Observability Forge v0.7 | Discover a missing data observation | Synthetic evidence |
| Observer Designer v0.8 | Authenticated local receipt instrument | Cooperating receiver |
| Open Instruments v0.9 | New combinations of schema joins | Finite equality language |
| Operator Genesis v1.0 | Composite admitted data operators | Small primitive inventory |
| Frontier One v1.1 | Active experimental probe for arithmetic model | Predefined model family |
| Ontological Genesis v1.2 | Stateless contradiction → two-state model | State machine family predetermined |
| Capability Closure v0.2 | Counterexamples to false novelty metrics | Finite modeled worlds |
| Invention Claim Gate v0.3 | Audit claims of structural, informational and resource expansion | Cannot certify global novelty |

Other programs: Philosopher's Stone/magician causal criteria, AI–human explanations, sentience categories, epistemology, ontology, proof access, SN models, RH and Mixed Paint.

**Standard:** preregister hypothesis → compare established baseline → test with unseen examples → challenge against counterexamples → validate genuine effect → preserve failure and ownership provenance.
