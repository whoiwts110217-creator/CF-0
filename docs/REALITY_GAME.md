# Real-World Adventure — Caveman Focus

Long-term vision: **business becomes enjoyable as a RuneScape-like adventure over reality**, with optional AR/holographic interface. Bitcoin was an analogy, not the essential goal.

| Game | Real equivalent |
|---|---|
| Quest board | Real approved tasks and opportunities |
| NPC/worker | Verified bounded automation |
| Lore | Source-preserved historical archive |
| Inventory | Actual approved tools, files and digital items |
| Mining/crafting | Useful productive work |
| Bank | Verified financial records, not an unlicensed banking service |
| Grand Exchange | Authorized real storefront and lawful transactions |
| Rewards | Genuine progress, sales only when actually paid |
| AR | Visual presentation on phone or headset |

The game should remain enjoyable independently of income. A virtual pickaxe/coin cannot mint real purchasing power merely through animation.

**Build order:** reliable engine → priority intelligence → verified operations → quest interface → optional spatial interface and community marketplace.
