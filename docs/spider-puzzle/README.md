# Spider Millennium Puzzle — AST v2 (public source-backed candidate)

**Purpose:** An offline, interactive visual assembly board for the Caveman Focus Spider v3.3.14 code. Browse file, class, function and JavaScript declaration pieces; inspect the original code; move pieces; connect hypotheses; and export or import layouts. No code is executed by connecting pieces.

**Creator / developer:** David Smith. **Intended owner / beneficiary:** Kiara Lynn Rose Smith. This credit is descriptive and does not establish a completed legal transfer.

## Open the puzzle

Open [index.html](./index.html) directly in a browser after downloading it. No cloud credentials, account connection, third-party JavaScript or paid service are required. The HTML contains its own source excerpts and graph data.

On the page, choose **Open Dependency Map (94 / 210)** to load the proposed compact file map. Select any piece to show only its relationships, then change **Wires** to All / Static source / Hypotheses only / Windows boundary as desired. From **Pieces Library**, select a function/class to inspect its exact source, origin, line range and purpose evidence. **Save Layout** downloads a JSON snapshot. **Code Assembly** is only a source/design export, not an installer.

## Structural evidence (not live working-software proof)

- 1,289 code pieces: 94 file pieces, 1,007 function pieces, 181 class pieces and 7 JavaScript declarations.
- 1,036 previously name-inferred purpose descriptions upgraded to deterministic static-AST/source-line summaries. These are **not** runtime confirmations or natural-language behavior proofs.
- 632 candidate relationships: 626 static-source and **6 explicitly hypothetical** edges; 164 edges carry a Windows HWND/SendInput boundary warning.
- A proposed 94-file map includes 210 source-mapped links. The included layout is compacted to fit the board and does not alter the source.
- No tests of actual Windows HP mouse/keyboard, logged-in Chrome, model output, or successful external operations are implied.

## Safety / integrity

The puzzle's code is inspectable but **never executed** by placing or linking a block. Preserve the original v3.3.14 source; this is an independent analysis/assembly candidate. User-generated layouts use their own `cf0_spider_puzzle_ast_v2_` browser storage namespace and do not overwrite earlier board layouts. Never interpret a manual wire as a proven working integration, and never auto-connect a Windows-control edge without a separate safety review and physical-device acceptance.

Original reference board: `SPIDER_PUZZLE_BOARD.html` in the private Caveman Focus Working Documents; public AST v2 derived from source ZIP fingerprint `438c442a781b028b1ef8fc336585e540e14dfb5e3828a8d2e8ab35857e2dec24`.
