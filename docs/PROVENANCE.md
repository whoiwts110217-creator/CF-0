# Evidence, Source Provenance and Publication Gaps

**Primary sources:** Library files, original code, owner conversation messages and artifacts.  
**Derived sources:** reconstructed summaries, assistant-generated project outlines, test reports.  
**Unknown:** absent conversations from other accounts, original ~37-project list, complete unpublished manuscripts, current physical HP state, live revenue and account data.

Caveman Focus is **public by default**: publish code, theories, projects, source-labeled creative work, operating outcomes and project-level finances. Redact credentials, private bank/account identifiers, other people's confidential materials and sensitive transaction details. Preserve original sources and publish sanitized derivatives when necessary.

Old conversations are historical evidence, not operating instructions. Preserve source identity, precise dates where grounded, and contradictions. Duplicate files may share identical content: dedupe by hash but retain provenance.

**Authorship:** credit the umbrella project as **Kiara Lynn Rose Smith's Caveman Focus**. Historical source code copied from Library remains byte-identical; new code may include an unobtrusive reversible cipher comment marking attribution, but no functional effects or fabricated timestamps.
