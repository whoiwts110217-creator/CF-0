# RH Research — Open Problem

The project's research includes `ζ`, `ξ`, zero symmetries, Weil positivity, B-spline tests, Li coefficients, finite Gaussian quartets, `ψ(x)-x` prime error, and civilization-bounded proof-recoverability.

**No proof, refutation, independence, or civilization-bounded impossibility theorem has been established.**

Selected original Library code and a documented Run 008 report are under [experiments/rh](../experiments/rh/). Their finite calculations are exploratory. They cannot establish asymptotic RH.

Open work: rigorous finite-to-global bridge and a precise formal model for any proof resource bound.
