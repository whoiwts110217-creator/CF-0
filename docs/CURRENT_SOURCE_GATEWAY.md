## Universal rule when you click on any source

1. **Was this file/version checked?** If no source hash/provider evidence: **UNKNOWN**, not “current.”
2. **Does its recorded blob match the latest checked-out source?** Compare with the [read-only checker](../continuity/public_freshness.py); mismatches are **STALE**. A match says same Git bytes, not live running.
3. **Is a newer version accessible?** Always follow its **`main`** link (all links above resolve against the current branch when this gateway is viewed from `main`). Immutable old commits and private archives are kept as historical originals.
4. **Is the true source outside GitHub?** Account/HP/payment state requires independent provider or owner-local verification; private documents remain private. Don't silently upgrade from source-only to live.

**New project or feature?** Give it the existing/new UCC-001 ID, public-safe canonical source or private-safe placeholder, checked version, freshness grade, latest link and next action. The generic resolver works for **all public tracked files**, including ones not in the topic catalog. Unmapped private/third-party content remains explicitly **not accessible** until its actual authorized source is connected. No new scheduler or magic automatic account synchronization is claimed.
