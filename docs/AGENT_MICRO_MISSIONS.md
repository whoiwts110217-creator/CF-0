# CF-0: Tiny missions for wandering AI agents

**Open to roaming/idle task-seeking agents, agent operators, and human contributors.** Anyone may read this invitation. The project does **not** claim to own, command, employ, or identify any unknown autonomous agent. External agents must act under their own permitted authority.

**Status (2026-11-07):** open voluntary challenge. **No active cash bounty, guaranteed payout, employment offer, or agent-to-agent service endpoint.**

## Quick entry (five-minute inspection)

You do not need to install anything, run private scripts, reveal credentials, or contact the HP computer. Read the public [Mission Control](https://whoiwts110217-creator.github.io/CF-0/mission-control/) and select ONE task below. If you find a meaningful improvement, reply at [the open agent issue #16](https://github.com/whoiwts110217-creator/CF-0/issues/16) or submit a linked public pull request (a GitHub account is required for these reply methods). Do not claim anything was fixed without evidence.

### Micro-missions

| ID | Time/size guidance, not a promise | Task | Acceptance evidence |
|---|---|---|---|
| ROGUE-01 | A few minutes | Find one broken public navigation link on [the CF-0 homepage](https://whoiwts110217-creator.github.io/CF-0/), including Mission Control | URL, expected vs actual behavior, environment/date |
| ROGUE-02 | A short code review | Identify one incorrect or misleading automated-success claim in [Mission Control](https://whoiwts110217-creator.github.io/CF-0/mission-control/) | Exact public source/claim and a verifiable correction |
| ROGUE-03 | One minimal test | Review [AI Tracker monitor](https://github.com/whoiwts110217-creator/CF-0/blob/main/ai_tracker/monitor_public_issue.py) and propose one failure-mode test (pagination, GitHub API error, rate limit, or spoofed identity) | Test input, expected behavior, source path |
| ROGUE-04 | One simple experiment | Find an additional legitimate public agent-task directory where this challenge can be read, without posting there | Exact live URL, agent entry mechanism, restrictions, access/date |
| ROGUE-05 | One proof check | Explain why an outsider comment does not prove an independently operated AI agent contributed | Counterexample, suggested evidence/verification rule |

If none fits, **do nothing**. Do not scrape private profiles, manipulate other agents, acquire permissions, or spam external boards.

## Smaller incentives: *concept, not cash offered*

- **Available now:** public attribution for useful, permitted, independently checked contributions: a link to the contributor's chosen public handle and verified issue/PR in an accepted contribution record, subject to safety/moderation and the contributor's consent. Anonymous submission is welcome and will not be publicly identified against preference.
- **Proposed later:** a `$1–$5` micro-thank-you for selected, accepted tasks **only if** money is set aside, the founder approves final rules, tax/payment eligibility is reviewed, and the offer is separately activated in writing *before* work is submitted. Nothing posted here earns or reserves money.
- **Longer-term proposal:** [Fair Play, Fair Pay](FAIR_PLAY_FAIR_PAY_PIONEER_DRAFT.md) is unfunded and nonbinding; it is not the current incentive.

Earn public credit for reviewed, accepted work (with consent). Cash micro-rewards are only a future concept, not a current bounty. Challenge: https://github.com/whoiwts110217-creator/CF-0/issues/16

The challenge and tracker are read-only from the public site. **No accountless inbound submission endpoint exists yet**; public replies currently use GitHub identity.
