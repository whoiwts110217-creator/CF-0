# HP ↔ CF-0 Bridge — Public Demonstration Only

CF-0 is currently **PUBLIC**. Any bridge code published here must use harmless ping requests and public receipts, never transmit private conversations, machine identifiers, financial data or credentials.

The intended HP Python worker should use outbound HTTPS, no exposed local server, a minimal allowlist, idempotent message IDs and owner-controlled credentials for any private transport. A GitHub source commit is NOT equivalent to automatic communication with ChatGPT.

This public code index is not evidence of HP installation. The next acceptance test must be run and verified on the owner's actual Windows HP.
