- `spider_desktop.py`: open Drive in Chrome (normal browser), review the local snapshot, or **explicitly approve** copying visible labels into a ChatGPT task draft. The draft is **not sent** until the owner separately uses the existing one-tab ChatGPT send controls. Nothing automatically crawls Drive or reads Docs content.
- Chrome permissions add `activeTab` and `scripting` for the owner-clicked tab; no blanket Google host permission. Previous debugger/ChatGPT bridge permissions are unchanged. Owner should review permissions before loading the extension.

**Private data boundary:** Reading file labels can reveal private filenames, even without file contents. Owner explicitly chooses the Drive tab and clicks Inspect, then separately approves any draft copy/share. Snapshot is not saved into the receipt journal, GitHub, or cloud by Spider's new feature. No credentials, OAuth, Google API connection, generalized browser worker or unattended Drive access.
