## New source functionality since v0.5

1. **Goal/missions:** `spider_missions.py` stores a private seven-step repair plan with dependencies, evidence notes and blocked/unknown handling. `spider_orchestrator.py` can perform several **read-only** steps after owner approval and STOP between files; it pauses at ChatGPT sending and code-changing gates.
2. **Project inspection and code diagnostics:** `spider_projects.py` performs a bounded local file inventory and syntax-only checks for Python/JSON and available JS/PowerShell parsers. Hidden directories, symlinks and oversize files are excluded. It **does not execute the repo's scripts or full test suite**.
3. **Repair with rollback:** `spider_patch_requests.py` accepts only a strict terminal `SPIDER_PATCH_REQUEST` JSON proposal from a completed selected-chat response. `spider_patches.py` stages a local exact-hash diff, refuses invalid Python/JSON syntax, shows it for a separate owner review, then **only after affirmative approval** replaces the exact reviewed file with a private backup. `spider_patch_store.py` persists a hash-checked rollback receipt; rollback requires separate owner approval.
4. **Source Skill Forge:** `spider_forge_requests.py` / `spider_forge.py` accept proposed skill *source* in Python, JavaScript or PowerShell, saving an **inactive, hash-verified `.source.txt` quarantine record**. No untrusted code is imported, installed, executed, or automatically enabled.
5. **Native GUI:** new controls for selecting workspace, starting/advancing mission, batching safe source steps, explicit single-file sharing to selected ChatGPT tab, reviewing patch proposals, rollback and reviewing skill-source drafts. Previous Vision/Hands, Chrome bridge, STOP and Skill Switchboard retained without extra extension permissions or model costs.
