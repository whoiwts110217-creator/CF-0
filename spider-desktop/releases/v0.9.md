## Two actual source-implemented paths

1. **Fixed recipes and hands.** `spider_recipes.py` provides owner-approved, fixed two-step Python project diagnostics (read-only inventory then syntax check) and `Notepad → pointer move → click once` via existing Win32 `spider_hands.py`. Physical mouse actions are constrained to an exact fresh, foreground empty untitled Notepad window; STOP and revalidation occur before effects. GUI buttons display each bounded sequence, with explicit owner consent. Unit tests use fake Windows backends; no real HP mouse result has been observed.
2. **Supervised GPT↔Python Brain.** `spider_brain.py` plus GUI controls propose/parse exactly one `SPIDER_BRAIN_DECISION` from a *matching completed* ChatGPT reply. Fixed allowlist: `inspect_project`, `syntax_audit`, `python_tests`, `ask_owner`, `finish`. Python executes only the owner-approved next tool, reduces evidence to sanitized counts/status, and stages the next ChatGPT prompt. **The owner must explicitly send each chat prompt and approve each local tool;** there is no unrestricted model-authored code execution, automatic infinite loop or cloud model bundled. Running trusted Python project tests is **not sandboxed** and may affect the owner machine. Unknown/failed ChatGPT replies cannot silently retry or execute. `finish` is a report, **not proof a task actually succeeded**.
3. **One scripted Google → ChatGPT route.** `chrome_extension/google_walk.js` and the popup add **Walk Google → ChatGPT**. After pairing/ARM and explicit popup action, from an already open `https://www.google.com/` homepage it fills one visible search field with `ChatGPT`, uses native Chrome debugger Enter, requires Google results, clicks only a visible *canonical* `https://chatgpt.com/` result and checks the same tab arrived. Exact Chrome host permission **`https://www.google.com/*`** is newly requested, alongside existing exact ChatGPT and localhost permissions; no all-sites permission. A new paired Python `/walk_gate` checks owner ARM/STOP between navigation stages. It neither chooses a private conversation nor signs in or sends prompts. DOM changes or missing results cause refusal. Only **mock browser acceptance** has been run.
