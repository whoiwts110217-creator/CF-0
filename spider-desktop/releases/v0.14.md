## Change over v0.13

1. **Chrome companion popup:** a new **VERIFY LIVE desktop connection** button sends exactly one `PING` command to its background.js. The background script sends a token-authenticated, exact-loopback `/heartbeat` request; requires the matching desktop `0.14` response. No ChatGPT send, tab navigation, paid connector request or external-memory sync.
2. **Desktop HTTP:** after exact paired extension Origin and token checks, `/heartbeat` updates an in-memory monotonic last-seen timestamp (no persistent remote store). False Origin, invalid token or stopped desktop are rejected. Ping does not arm, select or lease a job.
3. **Desktop UI:** separate LIVE / STALE / NOT RECEIVED companion indicator. A previously selected chat tab is **not** mistaken for proof of a currently responding extension. The existing 5-second watchdog refreshes the stale state. The signal expires after 45 seconds without another owner-clicked probe; STOP and re-pair clear it.
4. **Tests:** Controller unauthorized/stale/cleared ping, HTTP authenticated/unauthorized ping, actual Python HTTP + synthetic Chrome background-script handshake, GUI state transition checks. Prior v0.13 localhost-first-run test, 166 free/no-external-memory catalog, STOP, one-tab Chrome companion, project/patch/brain workflows are retained.
5. **No spending or third-party persistence:** all source changes use stdlib, existing optional Node tests and local Chrome; no API keys, external accounts, purchases, paid credit usage, memory/backup plugins, or new Chrome permissions.

## HP acceptance — one bounded human test

1. On Windows HP, close other active ChatGPT-writing extensions to prevent conflicting controllers. Unzip **v0.14** in a private local folder (do not mix old Chrome companion files) and run `START_SPIDER.cmd`.
2. Press **RUN LOCAL FIRST-RUN SELF-TEST** and verify **4/4 PASS**. This checks source integrity, manifest, local HTTP and zero-cost catalog, **not actual browser pairing**.
3. Load the unpacked **v0.14** `chrome_extension` in Chrome's Extensions page, review permissions, and obtain a fresh six-digit code from Spider Desktop. Click **Pair with HP** in Chrome, then click **VERIFY LIVE desktop connection**. Confirm the extension popup says a live `127.0.0.1` desktop answered and the *desktop* shows **CHROME LIVE CHECK: verified authenticated extension**. This is the first real acceptance signal we need.
4. Press **STOP** in Chrome and **STOP / DISCONNECT** on the desktop, then verify the desktop live indicator clears. No real ChatGPT message or Windows mouse action is required for this initial test. If blocked, collect only the displayed error string; never share PINs, tokens, chats, screenshots or passwords to public GitHub.
5. **Later, after that passes:** one safe selected ChatGPT conversation and one controlled send/reply, then separately Notepad/Windows hands, Google navigation and autonomous work. No claim of full autonomy until independently observed.
