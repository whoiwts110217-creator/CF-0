## Engineering change

The owner wants **both fixed click/type sequences AND Python-based tools with ChatGPT as a reasoning engine**. v0.9's hardcoded mouse and Google-to-ChatGPT route, source/patch tools and manual Brain still exist. New `spider_autopilot.py` and native GUI control **Start BOUNDED AUTO Brain** add a one-time owner review and approval for:

1. **At most three ChatGPT turns**, in one explicitly paired and selected Chrome conversation. The next message is only queued after the prior specific job's status and response match the paired desktop controller's completed browser report.
2. **At most two fixed local Python diagnostics** in the user-selected project: `inspect_project` and bounded `syntax_audit`. The model selects from a typed response schema, but cannot grant additional capabilities. The final ChatGPT turn can interpret the second diagnostic's result and report, not execute another tool.
3. Automatic STOP/hold on unconfirmed, duplicated, forged or unknown replies, changed selected tab, exhausted budget, pending human decision or tool failure. A model's `python_tests` request always pauses for **separate manual owner review**, because user test files are executable and not sandboxed. A `finish` answer is marked **reported_unverified**, never verified project repair.
4. No model-authored Python, external shell, unrestricted browser navigation, arbitrary mouse clicking, full-screen recognition, source patch application, skill installation, persistent background automation, purchases, account creation or file publication is enabled by this one approval. Local source metadata shared with ChatGPT may include up to six **relative source filenames/errors**; do not select a private project unless that is acceptable.
